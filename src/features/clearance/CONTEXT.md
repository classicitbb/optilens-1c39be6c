# Clearance catalogue
Standalone unlisted /clearance route. A random token in the URL fragment grants
read access through the clearance receiver; only its hash is stored server-side.
No navigation, sitemap or public search entry. Anyone holding the link can view.
Office publishes allowlisted sale snapshots with a scoped API key; the browser
never reads private inventory, costs or review notes. Expired snapshots hide stock.
Families group exact material/manufacturer/design/colour/type, with separate diameter
matrices. Single vision sells eaches by sphere/cylinder; multifocals sell complete
pairs by base/add. Publication/scheduling remain separately gated.
